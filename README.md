# همه‌جو

همه‌جو جای جستجوی آگهی است.

[hamejoo.ir](https://hamejoo.ir)

یک عبارت می‌نویسی و آگهی‌های مرتبط را یک‌جا می‌بینی؛ از مسکن و خودرو تا کالا و خدمات.

نتیجه را می‌بینی و برای جزئیات به منبع اصلی همان آگهی می‌روی.

## English

Hamejoo is a place to search listings.

It is for someone looking across housing, cars, goods, and services.

A visitor types a phrase and sees related listings in one place. The result is on Hamejoo; the listing detail is on the original source.

[hamejoo.ir](https://hamejoo.ir)
